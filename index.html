07
Open sourcePython

Judge-Aware Eval Gate

A CI gate for LLM-agent evals that separates judge unreliability from a real regression. A binary Dawid-Skene EM model jointly estimates each judge's sensitivity/specificity and the latent true pass rate with no ground truth required, and a Sidak alpha-spending budget keeps the gate's false-positive rate honest even when checked on every push -- unlike the popular eval tools, which gate on raw judge scores with a flat per-run p-value.

  • Python
  • NumPy/SciPy
  • EM / Dawid-Skene
  • GitHub Actions
